# 원어성경연구 ― 스트롱 코드 더블클릭 사전 연결

원어성경연구.exe에서 **스트롱 코드 번호를 더블 클릭하면** 스트롱 코드 사전이 바로 열려
원어·음역·발음·뜻·KJV 번역례·어원을 보여 줍니다. 인터넷이 없어도 됩니다.

## 들어 있는 파일

| 파일 | 하는 일 |
|---|---|
| `스트롱코드연결.ahk` | 더블 클릭을 감지해서 사전을 여는 프로그램 (AutoHotkey v2) |
| `스트롱코드사전.html` | 스트롱 히브리어 8,674단어 · 헬라어 5,523단어 사전 (오프라인) |
| `스트롱코드연결.ini` | 설정 파일 (메모장으로 수정) |
| `src/` | 사전을 다시 만들 때 쓰는 원본 자료와 스크립트 |

## 설치 (가장 쉬운 방법 — 한 번만)

1. `StrongsLink_Setup.zip`을 받아 **압축을 풉니다** (오른쪽 클릭 → 압축 풀기).
2. 풀린 폴더의 **`setup.bat`을 더블 클릭**합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다.
3. "설치가 끝났습니다!" 창이 뜨면 끝입니다.

설치 프로그램이 하는 일:
- `D:\내목회\원어성경연구(BibleWork 9 응용)` 폴더(없으면 D:\내목회 아래를 찾고, 그래도 없으면 폴더를 물어봄)에 파일 복사
- AutoHotkey를 따로 설치할 필요 없음 (실행 엔진 `AutoHotkey64.exe` 포함, 인터넷 불필요)
- 바탕화면에 **「원어성경연구 (스트롱 사전)」** 아이콘 생성 → 이것으로 원어성경연구를 켜면 됩니다
- 윈도우를 켤 때 사전 연결이 자동으로 준비되도록 시작프로그램 등록

## 직접 설치 (수동)

1. https://www.autohotkey.com 에서 AutoHotkey v2 설치
2. `스트롱코드연결.ahk`, `스트롱코드사전.html`, `스트롱코드연결.ini`를 원어성경연구 폴더에 복사
3. `스트롱코드연결.ahk` 더블 클릭

## 사용법

- 원어성경연구 창에서 **스트롱 코드 번호를 더블 클릭** → 사전 창이 뜹니다.
- 인식하는 모양: `H1254`, `G3056`, `<1254>`, `[H01254]`, `(G26)`, `히1254`, `헬3056`, `1254`
- 숫자만 있으면(예: `1254`) 히브리어와 헬라어 뜻을 **함께** 보여 줍니다.
- 사전 안의 어원에 나오는 `G3004` 같은 번호를 누르면 그 단어로 이동합니다.
- **Ctrl + Alt + F** : 어느 창에서든 글자를 선택하고 누르면 사전에서 찾습니다(선택이 없으면 입력창).
- **Ctrl + Alt + P** : 자동 연결을 잠시 멈추거나 다시 켭니다.

## 설정 (`스트롱코드연결.ini`)

| 항목 | 기본값 | 설명 |
|---|---|---|
| 대상프로그램 | `원어성경연구.exe\|bw900.exe\|bw.exe` | 더블 클릭을 감지할 프로그램 |
| 숫자만허용 | `1` | 절 번호 클릭에도 사전이 열려 불편하면 `0` (H/G 붙은 코드만) |
| 숫자만일때 | (비움) | `H`로 하면 숫자만 있을 때 히브리어로, `G`면 헬라어로 |
| 브라우저 | (비움) | 비우면 Edge → Chrome → 기본 브라우저 순 |
| 창하나만 | `1` | 새로 찾을 때 이전 사전 창을 닫음 |

> ini 파일은 **유니코드(UTF-16)** 로 저장되어 있습니다. 메모장에서 고친 뒤 그냥 저장하면 됩니다.
> 고친 뒤에는 아이콘 오른쪽 클릭 → 종료 → `스트롱코드연결.ahk` 다시 실행.

## 문제가 생기면

- **더블 클릭해도 아무 일이 없을 때**
  1. 작업 관리자 → 세부 정보에서 원어성경연구의 실제 프로그램 이름을 확인하고 `대상프로그램`에 넣어 주세요.
  2. 코드를 마우스로 드래그해서 선택한 뒤 **Ctrl+C**가 되는지 확인해 주세요.
     복사가 되지 않는 화면(그림처럼 그려진 글자)이면 자동 인식이 어렵습니다.
     그때는 **Ctrl+Alt+F** 를 눌러 번호를 입력해 찾으면 됩니다.
- **사전 창이 여러 개 뜰 때** : `창하나만=1` 인지 확인합니다.

## 실행 파일(.exe)로 만들기 (선택)

AutoHotkey 설치 후 `스트롱코드연결.ahk`를 오른쪽 클릭 → **Compile Script** 를 누르면
`스트롱코드연결.exe`가 만들어집니다. 이 exe는 AutoHotkey가 없는 컴퓨터에서도 실행됩니다.

## 사전 다시 만들기

```bash
node src/build_dictionary.js
```
