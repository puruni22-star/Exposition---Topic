# CLAUDE.md — My Note 볼트 작업 안내

이 폴더는 **기독교대한감리교회 지석교회(강화군 교동면) 담임목사**의 옵시디언 볼트입니다.
Claude는 이 볼트 안에서 설교 준비, 본문 연구, 양육·품성 자료 정리를 돕습니다.

## 회중과 목회 방향
- 재적 66명. 60대 이하 10%, 60대 50%, 70~80대 30%, 80대 이상 10%. 신앙은 신실한 편입니다.
- 핵심 메시지: **구원받은 성도답게 살아가라.** 웨슬리 신학(성화, 은혜의 수단)을 바탕으로 합니다.
- 고령 회중이므로 쉬운 말, 짧은 문장, 농촌 생활 예화를 씁니다.
- 목회 비전: 그리스도의 품성을 닮은 "작은 예수", 지역 주민과 함께하는 목회, 교동의 평화통일 기도.

## 폴더 구조
| 폴더 | 용도 |
|---|---|
| `_성경본문색인` | 성경 본문별 색인 노트 |
| `01_Raw` | 원자료(스크랩, 강의 메모, 녹취). **읽기만 하고 고치지 않습니다.** |
| `02_Wiki` | 원자료를 정리한 주제별 위키 노트 |
| `03_Project` | 진행 중인 작업(설교 시리즈, 행사 등) |
| `04_System` | 템플릿, 작업 규칙 |
| `05_Archive` | 끝난 작업 보관 |
| `21세기_MD`, `양육 시스템_MD`, `품성_MD` | 주제별 자료 모음 |
| `설교조안` | 설교 초안 |
| `BinData`, `Nexus` | 첨부 파일과 기타 자료 |

## 작업 규칙
1. 모든 글은 **한국어**로 씁니다. 성경 인용은 개역개정을 기본으로 합니다.
2. 노트끼리는 `[[위키링크]]`로 연결합니다. 본문 노트는 `_성경본문색인`에 링크를 남깁니다.
3. 새 노트 맨 위에는 YAML 프런트매터를 둡니다.
   ```yaml
   ---
   title:
   date: YYYY-MM-DD
   tags: []
   본문:
   ---
   ```
4. 파일을 **지우거나 옮기기 전에는 반드시 먼저 묻습니다.**
5. `01_Raw`에서 새 자료를 정리할 때는 `02_Wiki`에 노트를 만들고 원자료로 링크합니다.
6. 설교 초안은 `설교조안/YYMMDD_본문_제목.md` 형식으로 저장합니다.
7. `.obsidian` 폴더(옵시디언 설정)는 사용자가 요청할 때만 건드립니다.
