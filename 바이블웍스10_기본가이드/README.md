# 바이블웍스 10 기본 사용 가이드

유튜브 강의 「바이블웍스10 기본 — 무조건 따라 해 보세요」(채널 ‘한병욱 손우택’, 2023.04.20, 약 37분,
https://youtu.be/5Vw1JDYuKSg)의 자막을 바탕으로, 처음 쓰는 사람도 그대로 따라 할 수 있게 재구성한 안내서입니다.

| 파일 | 내용 |
|---|---|
| `바이블웍스10_기본사용가이드.docx` | Word 문서 (A4, 표지·차례·10장·부록, 18쪽) |
| `바이블웍스10_기본사용가이드.html` | HTML 문서 (상단 내비게이션, 모바일·다크 모드·인쇄 지원) |
| `src/content.js` | 원고 데이터 (Word·HTML 공용) |
| `src/build_docx.js`, `src/build_html.js` | 생성 스크립트 |

구성: 01 화면 구성 · 02 검색/표시 역본 개념 · 03 명령 입력 · 04 병행 역본(`d` 명령) · 05 원어 세팅(사전 순서·팝업·품사 색상·글꼴)
· 06 용례(Lemma) 검색 · 07 역본 즐겨찾기 · 08 한글 성경 설치 · 09 단어 통계 · 10 맺으며 · 부록 명령어 빠른 참조표

다시 생성하기 (Node + `docx` 패키지 필요):

```sh
cd 바이블웍스10_기본가이드
node src/build_docx.js "바이블웍스10_기본사용가이드.docx"
node src/build_html.js "바이블웍스10_기본사용가이드.html"
```
